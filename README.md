# Study-Flow
PBL project by Aditya Singh


**Changelog**

Implemented Features (from version 1.1 to 2.0):
1) Period duration changed to be in minutes instead of hours.
2) Always visible labels for everything in all the Add & Edit windows
3) Ability to edit & delete periods
4) A new 'Courses' section added where you can set these course/subject details, instead of the unintuitive way of doing it through attendance section.
5) UI adjustments made to routine section to make it more readable
6) When adding a routine item, if self-study is selected then the professor and room details won't be added
7) Interactive way to add periods by clicking on empty time blocks in the routine, just like google calendar
8) In assignments, in the adding task windows, an option for subject has been added
9) Clicking an occupied routine block opens its edit window
10) In the calendar, instead of using a dot to represent a deadline, a little rectangle with that task's name in the colour of its course/subject will be shown to view things at a glance
11) In the dashboard, the today's schedule will now display time in am/pm format
12) Deadlines are no longer mandatory for tasks/assignments
13) Date format changed to dd-mmm-yyyy (eg. 11 Nov 2025, 10 Sept 2026)
14) Option for subtasks within a task
15) Added an optional description option for tasks
16) Added the ability to edit tasks and its subtasks
17) Added an option to navigate between months
19) Backup file name format changed to: StudyFlow_backup_YYYY-MM-DD-hhmmss
20) Subject tag in assignment is now in the colour of the subject/course instead of grey
